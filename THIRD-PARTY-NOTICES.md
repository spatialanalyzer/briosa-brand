# Third-Party Notices

## Inter

`fonts/Inter-Variable.ttf` is the original Inter variable font, obtained from
the [Google Fonts Inter directory](https://github.com/google/fonts/tree/main/ofl/inter).
Its copyright notice, reserved font name and SIL Open Font License are
preserved in [fonts/OFL.txt](fonts/OFL.txt).

The slogan and product descriptors in the SVG artwork are outlines made
from Inter Regular. The custom Briosa wordmark is separate artwork traced
from the approved concept; it is not an Inter font variant.

## Build Tools

Python and Node dependencies are installed separately and retain their own
licenses. They are not vendored or bundled in brand releases. The optional
historical tracing tool is needed only to repeat the original image trace;
ordinary rebuilds use the committed vector outlines.
